# Instant Audio – plugin de Kino

Radios en vivo organizadas por **continente → país → lista de emisoras**.

## Navegación

1. **Inicio**
   - *Más escuchadas · Sudamérica* → tocas y suena (live)
   - Filas de continente (Sudamérica, Norteamérica, …) → **países** (bandera)
2. **Abrir un país** → lista de radios de ese país
3. **Elegir una radio** → reproducción en teléfono y TV

También: pestaña **En vivo**, búsqueda por nombre de emisora o país.

## Instalar

Repositorio público de GitHub con topic `kino-plugin`. En Kino: Ajustes → Plugins → `usuario/repo`.

## Ajustes

- Continente preferido en Inicio
- Radios por país (20–100)

## Datos

[Radio Browser API](https://api.radio-browser.info) — streams directos, sin anuncios de página.
